# Data Jobs Dashboard v2 w/ Power BI
![Dashboard Page 1](/Images/Proj2img1.png)
## Introduction
Navigating the data job market can feel overwhelming, with information spread across multiple sources. This dashboard (v2.0) is built specifically for **Job Seekers, Career Transitioners, and Role Switchers** to cut through the noise. Leveraging a real-world dataset of 2024 data science job postings—rich with details on titles, salaries, and locations—this project delivers a streamlined, single-page interface for quickly exploring key market trends and compensation insights.

## Skills Showcased

This project puts key Power BI capabilities into practice. Here’s what was accomplished:

* **🎨 Dashboard Design:** Creating an intuitive and visually engaging report layout.

* **🔄 Power Query (ETL):** Cleaning, shaping, and transforming the data.

* **🔗 Data Modeling:** Developing efficient models with relationships based on star schema principles.

* **🧠 DAX Fundamentals:** Building calculations and aggregations to generate meaningful insights.

* **📊 Visualizations Implemented:**

    * **📉 Core Charts:** Column, bar, line, and area charts for comparisons and trend analysis.

    * **🗺️ Map Charts:** Displaying geospatial information.

    * **🔢 KPI Cards:** Highlighting key performance indicators.

    * **📋 Tables:** Presenting detailed, structured data.

    * **🎭 Chart Variety:** Choosing the most effective visuals for clear data storytelling.

* **⚙️ Interactive Features:**

    * **🎛️ Slicers:** Enabling dynamic, user-driven filtering.

    * **🔘 Buttons & Bookmarks:** Streamlined navigation and managing report views (including drill-through).

## Dashboard Overview (Version 2.0 - Single Page Focus)
This second iteration brings the dashboard into a **single, focused page**, designed to provide job seekers with the most important market insights at a glance.

![Dashboard Page 1](/Images/Proj2img1.png)

This page serves as a compact mission control for the data job market, highlighting essential KPIs such as Job Count, Skills per Job, Median Yearly Salary, and Median Hourly Salary. It also enables quick views of skill popularity (by percentage or count) and salary comparisons across different job titles, all structured to deliver a fast and efficient overview.

## Conclusion
This updated dashboard (Version 2.0) demonstrates how Power BI can turn large volumes of job posting data into a focused and high-impact career analysis tool. It enables **job seekers, career transitioners, and role switchers** to filter and explore key market insights on a single page, supporting faster, more informed decisions about their next move.
